# Sovereign-AI Infrastructure

This repository contains two core pillars for sovereign-native AI development:

## 1. Sovereign-Immigration-Engine
Automated, PIPA-compliant KYC, OCR processing, visa policy validation, and immutable audit logging for foreign talent in Korea.

## 2. Fleet-Orchestrator
Multi-vendor industrial robot management with PQC-secured command dispatch and automated fault recovery.

## Deployment
See `sovereign-immigration-engine/deployment/docker-compose.yaml` to run services locally.
